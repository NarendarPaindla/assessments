# 2. Theory

## Why Not Just Return CartItem?

Current database:

### carts

| id | user_id |
| -- | ------- |
| 1  | 5       |

### cart_items

| id | cart_id | product_id | quantity |
| -- | ------- | ---------- | -------- |
| 1  | 1       | 10         | 2        |

Response:

```json
{
  "product_id": 10,
  "quantity": 2
}
```

Not useful.

Customer doesn't know:

```text
What product?
What price?
What total cost?
```

---

## Better Response

```json
{
  "product_name": "iPhone 15",
  "price": 79999,
  "quantity": 2,
  "item_total": 159998
}
```

---

## Grand Total

Example:

```text
iPhone     80,000 × 2
Laptop     50,000 × 1
Mouse       1,000 × 3
```

Calculation:

```text
160000

+3000
--------
213000
```

Grand Total:

```text
213000
```

## File: app/crud/cart.py

Add:

```python
def get_cart(
    db: Session,
    user_id: int
):

    cart = (
        db.query(Cart)
        .filter(
            Cart.user_id == user_id
        )
        .first()
    )

    if not cart:
        return {
            "items": [],
            "grand_total": 0
        }

    cart_items = (
        db.query(CartItem)
        .filter(
            CartItem.cart_id == cart.id
        )
        .all()
    )

    items = []

    grand_total = 0

    for item in cart_items:

        product = (
            db.query(Product)
            .filter(
                Product.id ==
                item.product_id
            )
            .first()
        )

        item_total = (
            product.price
            * item.quantity
        )

        grand_total += item_total

        items.append(
            {
                "product_id":
                product.id,

                "product_name":
                product.name,

                "price":
                product.price,

                "quantity":
                item.quantity,

                "item_total":
                item_total
            }
        )

    return {
        "items": items,
        "grand_total": grand_total
    }
```

# 9. Common Errors

---

## Error 1

```text
401 Unauthorized
```

Missing JWT.

---

## Error 2

```text
AttributeError Product None
```

Product deleted but cart item still exists.

We'll handle this later.

---

## Error 3

```text
grand_total incorrect
```

Check:

```python
product.price * item.quantity
```

---

## Error 4

```text
Empty response
```

User has no cart.

---

## Error 5

```text
N+1 Query Problem
```

We are querying Product inside a loop.

This is acceptable for now.

Later we will optimize with relationships and joins.
