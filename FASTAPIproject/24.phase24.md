# 2. Theory

## What is Pagination?

Pagination means:

```text
Large Data
     ↓
Small Chunks
```

Example:

Products:

```text
Product 1
Product 2
...
Product 100
```

Page Size:

```text
10
```

---

### Page 1

```text
1 - 10
```

---

### Page 2

```text
11 - 20
```

---

### Page 3

```text
21 - 30
```

---

## What is Limit?

Limit means:

```text
How many records?
```

Example:

```sql
LIMIT 10
```

Return only:

```text
10 rows
```

---

## What is Offset?

Offset means:

```text
Skip records
```

Example:

```sql
OFFSET 20
```

Skip:

```text
1 - 20
```

Start from:

```text
21
```

---

# Formula

## Page 1

```python
offset = (1 - 1) * 10
```

Result:

```text
0
```

---

## Page 2

```python
offset = (2 - 1) * 10
```

Result:

```text
10
```

---

## Page 3

```python
offset = (3 - 1) * 10
```

Result:

```text
20
```

---

# SQL Generated

Page 3:

```sql
SELECT *
FROM products
LIMIT 10
OFFSET 20;
```

## File: app/crud/product.py

Add:

```python
def paginate_products(
    db: Session,
    page: int,
    size: int
):

    total = (
        db.query(Product)
        .count()
    )

    offset = (
        (page - 1)
        * size
    )

    products = (
        db.query(Product)
        .offset(offset)
        .limit(size)
        .all()
    )

    return {
        "total": total,
        "page": page,
        "size": size,
        "data": products
    }
```

```python
@router.get(
    "/paginated/",
    response_model=
    ProductPaginationResponse
)
def paginated_products(
    page: int = 1,
    size: int = 10,
    db: Session = Depends(get_db)
):

    return paginate_products(
        db,
        page,
        size
    )
```


```python

```

---

## Apply Offset

```python
.offset(offset)
```

```text

```

---

## Apply Limit

```python
.limit(size)
```

Returns:

```text
10 rows
```

---


# 9. Common Errors

---

## Error 1

```text
page=0
```

Produces:

```python
offset = -10
```

Bad.

Later we will add validation.

For now:

```text
page >= 1
```

---

## Error 2

```text
size=100000
```

Huge response.

Later:

```text
max size = 100
```

---

## Error 3

```text
paginated treated as product_id
```

Route order issue.

Correct order:

```python
/search/
/filter/
/paginated/
/{product_id}
```

---

## Error 4

```text
Empty data
```

Page beyond available data.

Example:

```http
?page=100
```
