# 2. Theory

## Why Do We Need Schemas?

Current User Model:

```python
class User(Base):
    id = Column(Integer)
    name = Column(String)
    email = Column(String)
    password = Column(String)
    role = Column(String)
```

This is a **Database Model**.

Database models are not ideal for API requests.

Instead we create:

```python
UserCreate
```

for incoming data.

Example:

```json
{
  "name": "Narendar",
  "email": "narendar@gmail.com",
  "password": "admin123"
}
```

---

## Request Flow

```text
Swagger/Postman
        ↓
UserCreate Schema
        ↓
Validation
        ↓
Hash Password
        ↓
Save User
        ↓
Return UserResponse
```

---

## Why Not Return Password?

Bad:

```json
{
  "id": 1,
  "name": "Narendar",
  "password": "$2b$12$..."
}
```

Never expose passwords.

Instead:

```json
{
  "id": 1,
  "name": "Narendar",
  "email": "narendar@gmail.com",
  "role": "customer"
}
```

## File: app/schemas/user.py

```python
from pydantic import BaseModel, EmailStr


class UserCreate(BaseModel):
    name: str
    email: EmailStr
    password: str


class UserResponse(BaseModel):
    id: int
    name: str
    email: EmailStr
    role: str

    model_config = {
        "from_attributes": True
    }
```

---

## File: app/crud/user.py

```python
from sqlalchemy.orm import Session

from app.models.user import User
from app.schemas.user import UserCreate
from app.core.security import hash_password


def create_user(
    db: Session,
    user: UserCreate
):

    hashed_password = hash_password(
        user.password
    )

    db_user = User(
        name=user.name,
        email=user.email,
        password=hashed_password,
        role="customer"
    )

    db.add(db_user)

    db.commit()

    db.refresh(db_user)

    return db_user
```

---

## File: app/routers/user.py

```python
from fastapi import APIRouter
from fastapi import Depends

from sqlalchemy.orm import Session

from app.dependencies import get_db

from app.schemas.user import UserCreate
from app.schemas.user import UserResponse

from app.crud.user import create_user

router = APIRouter(
    prefix="/users",
    tags=["Users"]
)


@router.post(
    "/register",
    response_model=UserResponse
)
def register_user(
    user: UserCreate,
    db: Session = Depends(get_db)
):
    return create_user(
        db=db,
        user=user
    )
```

# 5. Explanation

---

## UserCreate Schema

```python
class UserCreate(BaseModel):
```

Used for request validation.

Expected request:

```json
{
  "name": "Narendar",
  "email": "narendar@gmail.com",
  "password": "admin123"
}
```

---

## EmailStr

```python
email: EmailStr
```

Valid:

```text
abc@gmail.com
```

Invalid:

```text
abcgmail.com
```

FastAPI automatically validates.

---

## UserResponse

Used for outgoing response.

```python
response_model=UserResponse
```

Password will never be returned.

---

## Hash Password

```python
hashed_password = hash_password(
    user.password
)
```

Before saving:

```text
admin123
```

After saving:

```text
$2b$12$abcd...
```

---

## db.add()

```python
db.add(db_user)
```

Marks object for insertion.

---

## db.commit()

```python
db.commit()
```

Actually writes to database.

---

## db.refresh()

```python
db.refresh(db_user)
```

Loads generated values.

Example:

```text
id=1
```

# 9. Common Errors

### Error 1

```text
ImportError: email-validator is not installed
```

Fix:

```bash
pip install email-validator
```

---

### Error 2

```text
422 Unprocessable Entity
```

Request body invalid.

Example:

```json
{
  "name": "Narendar"
}
```

Missing fields.

---

### Error 3

```text
AttributeError: model_config
```

Using old Pydantic version.

Check:

```bash
pip show pydantic
```

Use v2.

---

### Error 4

```text
sqlite3.IntegrityError
```

Usually duplicate email (once we add unique checks later).
