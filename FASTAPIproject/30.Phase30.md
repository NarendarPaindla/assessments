# 2. Theory

## Why Order History?

Customer buys:

```text
June 1
   ↓
iPhone
```

Then:

```text
June 20
   ↓
Laptop
```

Customer expects:

```text
My Orders
```

to show:

```text
Order #1
Order #2
```

---

## Order vs OrderItem

### Order

```text
Order #1001
```

Stores:

```text
User
Date
Status
```

---

### OrderItem

Stores:

```text
Product
Quantity
Price
```

---

Relationship:

```text
Order
 │
 ├── OrderItem
 │
 ├── OrderItem
 │
 └── OrderItem
```

## File: app/crud/order.py

Add:

```python
def get_order_history(
    db: Session,
    user_id: int
):

    orders = (
        db.query(Order)
        .filter(
            Order.user_id == user_id
        )
        .all()
    )

    response = []

    for order in orders:

        order_items = (
            db.query(OrderItem)
            .filter(
                OrderItem.order_id
                == order.id
            )
            .all()
        )

        items = []

        total_amount = 0

        for item in order_items:

            product = (
                db.query(Product)
                .filter(
                    Product.id ==
                    item.product_id
                )
                .first()
            )

            item_total = (
                item.price
                * item.quantity
            )

            total_amount += item_total

            items.append(
                {
                    "product_name":
                    product.name,

                    "quantity":
                    item.quantity,

                    "price":
                    item.price,

                    "total":
                    item_total
                }
            )

        response.append(
            {
                "order_id":
                order.id,

                "total_amount":
                total_amount,

                "items":
                items
            }
        )

    return response
```

### Add Route

```python
@router.get(
    "/history",
    response_model=
    list[OrderHistoryItem]
)

    db: Session = Depends(get_db),
```

# 5. Explanation

---

## Step 1

Find User Orders.

```python
db.query(Order)
```

Equivalent SQL:

```sql
SELECT *
FROM orders
WHERE user_id = 1;
```

---

## Step 2

Find Order Items.

```python
db.query(OrderItem)
```


# 9. Common Errors

### Error 1

```text
401 Unauthorized
```

Missing JWT.

---

### Error 2

```text
[]
```

User has no orders.

This is valid.

---

### Error 3

```text
Product is None
```

Product deleted after order creation.

In production, we'd store product snapshots.

---

### Error 4

```text
Incorrect total
```

Verify:

```python
item.price * item.quantity
```

---

### Error 5

```text
Slow response
```

N+1 query issue.

We'll optimize later using SQLAlchemy relationships and joins.
