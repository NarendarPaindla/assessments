# 2. Theory

## What Happens When Server Starts?

Current Code:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def home():
    return {
        "message": "Welcome to E-Commerce Backend API"
    }
```

When Uvicorn starts:

```text
Client
  ↓
Browser
  ↓
localhost:8000
  ↓
Uvicorn Server
  ↓
FastAPI App
  ↓
home()
  ↓
JSON Response
```

---

## What is Uvicorn?

FastAPI is only a framework.

It cannot listen for requests itself.

Uvicorn acts as the web server.

Example:

```text
FastAPI = Chef
Uvicorn = Waiter
```

The chef prepares food.

The waiter delivers food.

# 5. Explanation

## Understanding This Command

```bash
uvicorn app.main:app --reload
```

Let's break it down.

---

### app.main

```text
app/
   main.py
```

means:

```python
app.main
```

---

### app

Inside main.py:

```python
app = FastAPI()
```

This is the FastAPI instance.

So:

```text
app.main:app
```

means:

```text
Go to app/main.py
Use variable app
```

---

### --reload

Automatically restarts server when code changes.

Without reload:

```text
Change Code
 ↓
Stop Server
 ↓
Restart Server
```

With reload:

```text
Change Code
 ↓
Auto Restart
```

Useful during development.

# 9. Common Errors

---

## Error 1

```text
ModuleNotFoundError: No module named 'app'
```

Reason:

Running command from wrong folder.

Wrong:

```text
Desktop
```

Correct:

```text
ecommerce_backend
```

Run:

```bash
cd ecommerce_backend
uvicorn app.main:app --reload
```

---

## Error 2

```text
'uvicorn' is not recognized
```

Reason:

Uvicorn not installed.

Fix:

```bash
pip install uvicorn
```

---

## Error 3

```text
Address already in use
```

Port 8000 already occupied.

Use another port:

```bash
uvicorn app.main:app --reload --port 8001
```

Then open:

```text
http://127.0.0.1:8001
```

---

## Error 4

```text
SyntaxError in main.py
```

Reason:

Typing mistake.

Verify:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def home():
    return {
        "message": "Welcome to E-Commerce Backend API"
    }
```

---

## Error 5

```text
404 Not Found
```

Reason:

Wrong URL.

Correct:

```text
http://127.0.0.1:8000/
```
