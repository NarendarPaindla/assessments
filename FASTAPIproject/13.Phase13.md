# 2. Theory

---

## Never Store Plain Passwords

Bad Example:

| id | email                                           | password |
| -- | ----------------------------------------------- | -------- |
| 1  | [narendar@gmail.com](mailto:narendar@gmail.com) | 123456   |

If database leaks:

```text id="5lx1wr"
Attacker sees:
123456
```

Very dangerous.

---

## What is Hashing?

Hashing converts:

```text id="ojw6zz"
123456
```

into:

```text id="vpd4xq"
$2b$12$K8jYx7v....
```

Example:

```python id="7rb4x8"
password
      ↓
Hash Function
      ↓
Encrypted String
```

---

## Important

Hashing is **one-way**.

You cannot convert:

```text id="0fv85m"
$2b$12$K8jY...
```

back into:

```text id="8e45ns"
123456
```

---

## Login Flow

User enters:

```text id="nql9zy"
123456
```

System:

```text id="qvjl31"
Hash entered password
      ↓
Compare with stored hash
      ↓
Match?
      ↓
Login Success
```

---

## Why bcrypt?

bcrypt provides:

✅ Strong Security

✅ Salt Generation

✅ Industry Standard

✅ Used in Production

---

## Why Passlib?

Passlib makes password hashing easy.

Instead of writing complex cryptography:

```python id="k1v4vb"

```

# 4. Full Code

---

## File: app/core/security.py

Create:

```python id="d2d5z4"
from passlib.context import CryptContext

pwd_context = CryptContext(
    schemes=["bcrypt"],
    deprecated="auto"
)


def hash_password(password: str) -> str:
    return pwd_context.hash(password)


def verify_password(
    plain_password: str,
    hashed_password: str
) -> bool:
    return pwd_context.verify(
        plain_password,
        hashed_password
    )
```

---

## File: app/main.py

Replace with:

```python id="j1ydgj"
from fastapi import FastAPI

from app.core.security import hash_password
from app.core.security import verify_password

app = FastAPI()


@app.get("/")
def home():

    password = "123456"

    hashed = hash_password(password)

    verified = verify_password(
        "123456",
        hashed
    )

    return {
        "original_password": password,
        "hashed_password": hashed,
        "verified": verified
    }
```

# Why Hash Changes Every Time?

Try:

```python id="g46wmb"
hash_password("123456")
```

multiple times.

Outputs:

```text id="m8l4a5"
$2b$12$ABC...
$2b$12$XYZ...
$2b$12$LMN...
```

Different each time.

This is because bcrypt adds a random salt.

---

Yet:

```python id="vqfd69"
verify_password(...)
```

still works.

```bash id="3xdn5x"

```

---

## Error 2

```text id="g9nkjd"

```

Fix:

```bash id="m8w0s6"

```

---

## Error 3

```text id="n7ew7l"

```

Usually caused by old bcrypt version.

Upgrade:

```bash id="ydx6mu"
pip install --upgrade bcrypt
```

---

## Error 4

```text id="yzljxq"

```

Wrong:

```python id="4lfl78"

    "wrong_password",
    hash
)
```

Must use same password.
