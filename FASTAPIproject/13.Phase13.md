# 2. Theory

---

## What Happens Right Now?

Current Situation:

```text
Models
   ↓
Migration File
   ↓
Database
```

Migration exists.

But database has not executed it yet.

---

## What Does Upgrade Mean?

Upgrade means:

```text
Take Migration File
       ↓
Execute upgrade()
       ↓
Create Tables
       ↓
Update Database Version
```

---

## What is `head`?

Suppose you have:

```text
Migration 1
Migration 2
Migration 3
Migration 4
```

Latest migration:

```text
Migration 4
```

is called:

```text
head
```

---

When you run:

```bash
alembic upgrade head
```

Alembic applies all pending migrations.

---

## How Alembic Tracks Versions

Alembic creates a special table:

```text
alembic_version
```

Example:

| version_num |
| ----------- |
| abc123      |

This tells Alembic:

```text
Database is currently at revision abc123
```

# 5. Explanation

---

## Command Breakdown

### alembic

Runs Alembic CLI.

---

### upgrade

Move database forward.

---

### head

Apply all migrations until latest version.

---

Equivalent Flow:

```text
Database
    ↓
Migration 1
    ↓
Migration 2
    ↓
Migration 3
    ↓
HEAD
```

---

## Internally What Happens?

Alembic:

```text
Read alembic_version
      ↓
Find Pending Migration
      ↓
Run upgrade()
      ↓
Create Tables
      ↓
Update alembic_version
```

# 9. Common Errors

---

## Error 1

```text
Target database is not up to date
```

Fix:

```bash
alembic upgrade head
```

---

## Error 2

```text
No such table
```

Reason:

Migration not applied.

Run:

```bash
alembic upgrade head
```

---

## Error 3

```text
Can't locate revision
```

Migration file missing.

Check:

```text
alembic/versions/
```

contains migration file.

---

## Error 4

```text
database is locked
```

Close:

```text
DB Browser for SQLite
```

before running migrations.

---

## Error 5

```text
No module named app
```

Run commands from:

```text
ecommerce_backend/
```

root folder.

# 10. Rollback Concept (Important)

Suppose migration breaks production.

Alembic allows rollback.

Current:

```text
Migration 2
```

Go back:

```bash
alembic downgrade -1
```

Meaning:

```text
Go back one migration
```

We won't execute rollback now.

Just understand the concept.
