# 2. Theory

---

## What Happens Now?

Until now:

```text
User Model
   ↓
Only Python Class
```

Example:

```python
class User(Base):
    __tablename__ = "users"
```

This exists only in Python.

No actual database table yet.

---

## What We Need

We need:

```text
FastAPI
   ↓
SQLAlchemy
   ↓
SQLite
```

Connection Flow:

```text
User Request
      ↓
FastAPI
      ↓
Session
      ↓
Engine
      ↓
SQLite Database
```

---

## What is an Engine?

Engine is the bridge between Python and Database.

```text
Python
   ↔
Engine
   ↔
SQLite
```

Example:

```python
engine = create_engine(...)
```

---

## What is SessionLocal?

Session is used to talk to database.

Example:

```python
db.add(user)
db.commit()
```

The `db` object comes from Session.

Think:

```text
Engine = Road
Session = Vehicle
```

---

## What is Metadata?

SQLAlchemy stores information about tables.

Example:

```python
class User(Base):
```

SQLAlchemy remembers:

```text
users table
id column
name column
email column
```

This information is called Metadata.

---

## What Does create_all() Do?

```python
Base.metadata.create_all(bind=engine)
```

Meaning:

```text
Check all models
     ↓
Create tables if missing
```

# 4. Full Code

---

## File: app/database.py

Replace everything:

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import declarative_base
from sqlalchemy.orm import sessionmaker

DATABASE_URL = "sqlite:///./ecommerce.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False}
)

SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)

Base = declarative_base()
```

---

## File: app/models/user.py

Keep:

```python
from sqlalchemy import Column, Integer, String

from app.database import Base


class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, index=True)
    name = Column(String, nullable=False)
    email = Column(String, unique=True, nullable=False)
```

---

## File: app/models/**init**.py

```python
from app.models.user import User
```

---

## File: app/main.py

Replace everything:

```python
from fastapi import FastAPI

from app.database import Base
from app.database import engine

import app.models

Base.metadata.create_all(bind=engine)

app = FastAPI()


@app.get("/")
def home():
    return {
        "message": "Welcome to E-Commerce Backend API"
    }
```

# 5. Explanation

---

# database.py

---

## Database URL

```python
DATABASE_URL = "sqlite:///./ecommerce.db"
```

Meaning:

```text
sqlite
     ↓
use SQLite database

./
     ↓
current folder

ecommerce.db
     ↓
database file name
```

Result:

```text
ecommerce_backend/
│
├── ecommerce.db
```

---

## Create Engine

```python
engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False}
)
```

Creates connection to SQLite.

---

### Why check_same_thread=False?

SQLite normally allows:

```text
One Thread Only
```

FastAPI uses multiple threads.

Therefore:

```python
connect_args={"check_same_thread": False}
```

is required.

---

## Create Session Factory

```python
SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)
```

Creates database sessions.

Later:

```python
db = SessionLocal()
```

will create connection objects.

---

## Create Base

```python
Base = declarative_base()
```

Parent class for all models.

---

# User Model

---

## Primary Key

```python
id = Column(
    Integer,
    primary_key=True,
    index=True
)
```

Meaning:

```text
INTEGER PRIMARY KEY
```

---

## Index

```python
index=True
```

Creates database index.

Search becomes faster.

---

## Name

```python
name = Column(
    String,
    nullable=False
)
```

Meaning:

```text
Must contain value
```

Cannot be:

```text
NULL
```

---

## Email

```python
email = Column(
    String,
    unique=True,
    nullable=False
)
```

Meaning:

```text
No duplicate emails
```

Valid:

```text
a@gmail.com
b@gmail.com
```

Invalid:

```text
a@gmail.com
a@gmail.com
```

# 9. Common Errors

---

## Error 1

```text
No such table users
```

Reason:

Model not imported.

Check:

```python
import app.models
```

exists in main.py.

---

## Error 2

```text
ModuleNotFoundError
```

Run from project root:

```bash
cd ecommerce_backend
```

---

## Error 3

```text
database is locked
```

Close:

```text
DB Browser
```

or any app using SQLite.

---

## Error 4

```text
sqlite3.OperationalError
```

Check:

```python
DATABASE_URL = "sqlite:///./ecommerce.db"
```

exactly.

---

## Error 5

```text
users table not created
```

Check:

```python
Base.metadata.create_all(bind=engine)
```

exists.
