# 2. Theory

---

## What is Search?

Without Search:

```text
Product 1
Product 2
Product 3
...
Product 10000
```

User manually searches.

Very bad UX.

---

With Search:

```http
GET /products/search?q=iphone
```

Result:

```text
iPhone 15
iPhone 15 Pro
```

---

## Exact Match vs Partial Match

### Exact Match

SQL:

```sql
WHERE name = 'iphone'
```

Only matches:

```text
iphone
```

---

### Partial Match

SQL:

```sql
WHERE name LIKE '%iphone%'
```

Matches:

```text
iphone
iphone 15
iphone charger
new iphone
```

Much better.

---

## What is `%`?

In SQL:

```text
%
```

means:

```text
Any Characters
```

Examples:

```sql
LIKE '%iphone%'
```

Matches:

```text
iphone
iphone 15
best iphone
new iphone pro
```

---

## Query Parameters

URL:

```http
/products/search?q=iphone
```

Here:

```text
q
```

is a query parameter.

FastAPI automatically extracts it.

Example:

```python
def search_products(q: str):
```

# 4. Full Code

---

## File: app/crud/product.py

Add this function below existing CRUD functions.

```python
def search_products(
    db: Session,
    query: str
):

    return (
        db.query(Product)
        .filter(
            Product.name.ilike(
                f"%{query}%"
            )
        )
        .all()
    )
```

---

# Why ilike()?

```python
Product.name.ilike(...)
```

Performs:

```sql
LOWER(name)
```

comparison.

Meaning:

Search:

```text
iphone
```

Matches:

```text
IPHONE
iPhone
iphone
IpHoNe
```

Case-insensitive.

---

## File: app/routers/product.py

```python

```

### Add Search Route

IMPORTANT:

Place this route ABOVE:

```python
@router.get("/{product_id}")
```

Otherwise FastAPI thinks:

```text
search
```

is a product_id.

---

```python
@router.get(
    "/search/",
    response_model=list[ProductResponse]
)
def search_product_list(
    q: str,
    db: Session = Depends(get_db)
):

    return search_products(
        db,
        q
    )
```

# 9. Common Errors

---

## Error 1

```text
422 Validation Error
```

Usually route order issue.

Wrong:

```python
@router.get("/{product_id}")
@router.get("/search/")
```

Correct:

```python
@router.get("/search/")
@router.get("/{product_id}")
```

---

## Error 2

```text
search treated as product_id
```

Same issue.

Move search route above dynamic route.

---

## Error 3

```text
No results found
```

Check product names.

---

## Error 4

```text
AttributeError: Product has no attribute name
```

Verify Product model.
