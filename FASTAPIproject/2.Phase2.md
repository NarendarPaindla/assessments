# 2. Theory

## Why Folder Structure Matters?

Imagine building a shopping mall.

Would you keep:

* Products
* Bills
* Security
* Management

all in one room?

No.

Each department gets its own place.

Backend projects follow the same principle.

Bad Project:

```text
main.py
database.py
user.py
product.py
order.py
cart.py
auth.py
payment.py
```

After 100+ files:

```text
😱 Impossible to maintain
```

---

## Professional Structure

```text
app/
├── main.py
├── database.py
├── models/
├── schemas/
├── crud/
├── routers/
├── services/
├── core/
├── uploads/
├── tests/
└── utils/
```

Every folder has a responsibility.

---

## Understanding Each Folder

---

### app/

Main application folder.

Contains everything.

```text
app/
```

---

### main.py

Entry point.

Starts FastAPI.

```python
app = FastAPI()
```

Equivalent:

```text
Main Gate of Shopping Mall
```

---

### database.py

Handles:

* SQLite Connection
* Session Creation
* Engine

Equivalent:

```text
Electricity Supply Room
```

---

### models/

Database tables.

Examples:

```text
User
Product
Category
Order
Cart
```

SQLAlchemy Models live here.

---

### schemas/

Pydantic Models.

Used for:

* Request Validation
* Response Formatting

Example:

```json
{
  "name":"Laptop",
  "price":50000
}
```

Validated here.

---

### crud/

CRUD =

Create

Read

Update

Delete

Database operations go here.

Example:

```python

get_user()
update_user()
delete_user()
```

---

### routers/

API Endpoints.

Example:

```python
POST /users
GET /products
POST /orders
```

---

### services/

Business Logic.

Example:

```text
Create Order
Calculate Total
Apply Discount
Process Payment
```

---

### core/

Application Core Settings.

Contains:

```text
JWT
Security
Permissions
Config
```

---

### uploads/

Stores uploaded files.

Example:

```text
uploads/
   product1.jpg
   product2.png
```

---

### tests/

Pytest test cases.

Example:

```python
test_login()
test_register()
```

---

### utils/

Helper Functions.

Example:

```python
generate_invoice()
send_email()
```

# 5. Explanation

---

## What is **init**.py ?

Python treats folders as packages when they contain:

```text
__init__.py
```

Without:

```text
models/
```

With:

```text
models/
└── __init__.py
```

Python can import from it.

Example:

```python
from app.models import user
```

---

## Why Create Empty Files?

We are following:

```text
Architecture First
Code Second
```

Professional teams create structure before implementation.

---

## Why requirements.txt ?

Allows anyone to install project dependencies.

Example:

```bash
pip install -r requirements.txt
```

# 9. Common Errors

---

## Error 1

```text
No module named app
```

Reason:

Missing:

```text
__init__.py
```

Fix:

Create all init files.

---

## Error 2

```text
mkdir: command not found
```

Reason:

Wrong shell.

Use:

Windows CMD:

```cmd
md foldername
```

or

```cmd
mkdir foldername
```

---

## Error 3

```text
tree is not recognized
```

Install tree or use:

```bash
dir
```

or

```bash
ls -R
```
