# 2. Theory

## What is ORM?

ORM = Object Relational Mapper

ORM acts as a translator between:

```text
Python Objects
      ↕
Database Tables
```

Without ORM:

```sql
INSERT INTO users(name,email)
VALUES('Narendar','n@gmail.com');
```

You must write SQL manually.

---

With ORM:

```python
user = User(
    name="Narendar",
    email="n@gmail.com"
)
```

Much easier.

---

## SQLAlchemy

SQLAlchemy is the most popular ORM in Python.

It allows us to:

✅ Create tables

✅ Insert records

✅ Update records

✅ Delete records

✅ Query records

using Python code.

---

## ORM Mapping Example

Database Table:

```text
users
```

| id | name     |
| -- | -------- |
| 1  | Narendar |

Equivalent Python Class:

```python
class User:
    id
    name
```

SQLAlchemy maps:

```text
Python Class
      ↕
Database Table
```

---

## What is Engine?

Engine creates connection between:

```text
FastAPI
   ↓
SQLAlchemy
   ↓
SQLite Database
```

Think:

```text
Engine = Bridge
```

---

## What is Declarative Base?

Every model must inherit from Base.

Example:

```python
class User(Base):
    ...
```

Why?

Because SQLAlchemy needs to know:

```text
This class should become a table
```

---

## How SQLAlchemy Creates Tables

Python:

```python
class User(Base):
    ...
```

Becomes:

```sql
CREATE TABLE users(...)
```

internally.

# Internal Working

Python:

```python
class User(Base):
```

SQLAlchemy reads:

```text
Create table users
```

---

Python:

```python
id = Column(Integer)
```

SQLAlchemy reads:

```text
Create integer column id
```

---

Python:

```python
name = Column(String)
```

SQLAlchemy reads:

```text
Create string column name
```

---

Final SQL Generated Internally

```sql
CREATE TABLE users(
    id INTEGER PRIMARY KEY,
    name VARCHAR,
    email VARCHAR
);
```

You never write this manually.

SQLAlchemy generates it.

# 9. Common Errors

---

## Error 1

```text
ModuleNotFoundError: No module named app
```

Reason:

Running Python from wrong folder.

Correct:

```bash
cd ecommerce_backend
python
```

---

## Error 2

```text
NameError: Base not defined
```

Reason:

Forgot:

```python
from app.database import Base
```

---

## Error 3

```text
Column is not defined
```

Reason:

Forgot imports.

Correct:

```python
from sqlalchemy import Column, Integer, String
```

---

## Error 4

```text
IndentationError
```

Wrong:

```python
class User(Base):
__tablename__ = "users"
```

Correct:

```python
class User(Base):
    __tablename__ = "users"
```
