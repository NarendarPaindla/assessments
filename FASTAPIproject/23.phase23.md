# 4. Full Code

---

## File: app/crud/product.py

Add:

```python
def filter_products(
    db: Session,
    category_id: int | None = None,
    min_price: float | None = None,
    max_price: float | None = None
):

    query = db.query(Product)

    if category_id is not None:

        query = query.filter(
            Product.category_id == category_id
        )

    if min_price is not None:

        query = query.filter(
            Product.price >= min_price
        )

    if max_price is not None:

        query = query.filter(
            Product.price <= max_price
        )

    return query.all()
```

    max_price: float | None = None,

    return filter_products(
        db=db,

        max_price=max_price

# 5. Explanation

---

## Dynamic Query Building

Start:

```python
query = db.query(Product)
```

Equivalent:

```sql
SELECT *
FROM products
```

---

### Add Category Filter

```python
query = query.filter(
    Product.category_id == category_id
)
```

SQL:

```sql
WHERE category_id = 1
```

---

### Add Min Price

```python
Product.price >= min_price
```

SQL:

```sql
price >= 10000
```

---

### Add Max Price

```python
Product.price <= max_price
```

SQL:

```sql
price <= 50000
```

---

### Final Query Example

Request:

```http
/products/filter?category_id=1&max_price=80000
```

Generated SQL roughly:

```sql
SELECT *
FROM products
WHERE category_id = 1
AND price <= 80000;
```

---

# Why Use Optional Parameters?

```python
category_id: int | None = None
```

Meaning:

```text
Parameter is optional
```

Works:

```http
/products/filter
```

or

```http
/products/filter?category_id=1
```

or

```http
/products/filter?max_price=50000
```

---

# Internal Flow

```text
Request
   ↓
Read Query Parameters
   ↓
Build Query Dynamically
   ↓
Execute SQL
   ↓
Return Matching Products
```

# 9. Common Errors

---

## Error 1

```text
422 Validation Error
```

Wrong type:

```http
/products/filter/?category_id=abc
```

Must be integer.

---

## Error 2

```text
No products returned
```

Filters too restrictive.

Example:

```http
/products/filter/?max_price=10
```

---

## Error 3

```text
filter route treated as product_id
```

Route order issue.

Place:

```python
@router.get("/filter/")
```

above:

```python
@router.get("/{product_id}")
```

---

## Error 4

```text
search route conflict
```

Correct order:

```python
/search/
/filter/
/{product_id}
```

---

# Recommended Route Order

```python
@router.get("/search/")
@router.get("/filter/")
@router.get("/{product_id}")
```

This avoids conflicts.
