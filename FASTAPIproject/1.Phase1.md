## What is a Virtual Environment?

A Virtual Environment creates an isolated Python environment for a project.

Without Virtual Environment:

```text
Laptop
 ├── Project A
 ├── Project B
 └── Project C

All share same packages
```

With Virtual Environment:

```text
Project A
 └── own packages

Project B
 └── own packages

Project C
 └── own packages
```

This prevents package conflicts.

---

## What is FastAPI?

FastAPI is a modern Python framework used for building APIs.

Example:

```python
@app.get("/")
def home():
    return {"message": "Hello"}
```

When user visits:

```text
http://localhost:8000/
```

Response:

```json
{
  "message":"Hello"
}
```

---

## What is Uvicorn?

FastAPI does not run by itself.

Uvicorn is the web server that runs FastAPI applications.

Think:

```text
FastAPI = Car
Uvicorn = Driver
```

---

## What is SQLAlchemy?

SQLAlchemy is an ORM.

ORM = Object Relational Mapper.

Instead of writing:

```sql
SELECT * FROM users;
```

We write:

```python
db.query(User).all()
```

---

## What is Alembic?

Alembic manages database migrations.

Example:

Today:

```python
User
 ├── id
 └── name
```

Tomorrow:

```python
User
 ├── id
 ├── name
 └── email
```

Alembic updates database safely.

---

## What is JWT?

JWT = JSON Web Token

Used for authentication.

Example:

```text
Login
 ↓
Generate Token
 ↓
Access Protected APIs
```

---

## What is Passlib?

Passlib hashes passwords.

Never store:

```text
123456
```

Store:

```text
$2b$12$asdkjaskd...
```

---

## What is python-multipart?

Used for file uploads.

Example:

```text
Product Image Upload
Profile Image Upload
Document Upload
```

# 9. Common Errors

---

## Error 1

```text
python is not recognized
```

Reason:

```text
Python not installed
```

Fix:

Install Python and select:

```text
✓ Add Python to PATH
```

during installation.

---

## Error 2

```text
pip is not recognized
```

Fix:

```bash
python -m pip install --upgrade pip
```

---

## Error 3

```text
Execution Policy Error
```

PowerShell:

```text
running scripts is disabled
```

Fix:

Open PowerShell as Administrator:

```powershell
Set-ExecutionPolicy RemoteSigned
```

Then:

```powershell
.\venv\Scripts\Activate.ps1
```

---

## Error 4

```text
ModuleNotFoundError
```

Reason:

Virtual environment not activated.

Fix:

```bash
venv\Scripts\activate
```
