# Step 8: Session Management

This is one of the most important concepts in FastAPI + SQLAlchemy.

Without proper session management:

❌ Database connections remain open

❌ Memory leaks occur

❌ Application becomes slow

❌ Database gets locked

Professional applications always use session management.

---

# 2. Theory

---

## What is a Session?

Think of a database session as a temporary conversation with the database.

Example:

```text
FastAPI
   ↓
Session
   ↓
SQLite
```

When a request arrives:

```text
GET /users
```

FastAPI:

```text
Open Session
      ↓
Query Database
      ↓
Return Result
      ↓
Close Session
```

---

## Why Not Use One Global Session?

Wrong:

```python
db = SessionLocal()
```

at application startup.

Problem:

```text
All Users
   ↓
Same Session
```

Results:

❌ Locked Database

❌ Data Corruption

❌ Memory Issues

---

Correct:

```text
Request 1
   ↓
Session 1

Request 2
   ↓
Session 2

Request 3
   ↓
Session 3
```

Each request gets its own session.

---

## What is Dependency Injection?

FastAPI can automatically provide objects to functions.

Example:

```python
def get_current_user():
    ...
```

FastAPI injects it.

We will inject:

```python
db
```

automatically.

---

## What is Depends()?

Example:

```python
db: Session = Depends(get_db)
```

Meaning:

```text
FastAPI:

Run get_db()

Take returned value

Pass it into db
```

# 4. Full Code

---

## File: app/database.py

Replace with:

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import declarative_base
from sqlalchemy.orm import sessionmaker

DATABASE_URL = "sqlite:///./ecommerce.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False}
)

SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)

Base = declarative_base()
```

---

## File: app/dependencies.py

Create:

```python
from app.database import SessionLocal


def get_db():
    db = SessionLocal()

    try:
        yield db

    finally:
        db.close()
```

---

## File: app/main.py

Replace everything:

```python
from fastapi import Depends
from fastapi import FastAPI

from sqlalchemy.orm import Session

from app.database import Base
from app.database import engine

from app.dependencies import get_db

import app.models

Base.metadata.create_all(bind=engine)

app = FastAPI()


@app.get("/")
def home(
    db: Session = Depends(get_db)
):
    return {
        "message": "Welcome to E-Commerce Backend API"
    }
```

# dependencies.py

This file contains reusable dependencies.

---

## Import SessionLocal

```python
from app.database import SessionLocal
```

Allows us to create sessions.

---

## get_db()

```python
def get_db():
```

Creates database dependency.

---

### Create Session

```python
db = SessionLocal()
```

Equivalent:

```text
Open Database Connection
```

---

### Try Block

```python
try:
```

Database operations happen here.

---

### Yield

```python
yield db
```

Important.

FastAPI pauses here.

Returns:

```python
db
```

to route.

---

Example:

```python
db: Session = Depends(get_db)
```

receives:

```python
db
```

from yield.

---

### Finally

```python
finally:
```

Always runs.

Even if:

```text
Exception occurs
```

---

### Close Session

```python
db.close()
```

Equivalent:

```text
Close Database Connection
```

# 9. Common Errors

---

## Error 1

```text
NameError: Depends not defined
```

Fix:

```python
from fastapi import Depends
```

---

## Error 2

```text
SessionLocal not defined
```

Fix:

```python
from app.database import SessionLocal
```

---

## Error 3

```text
TypeError: object is not callable
```

Wrong:

```python
Depends(get_db())
```

Correct:

```python
Depends(get_db)
```

Notice:

```text
No parentheses
```

---

## Error 4

```text
database is locked
```

Usually happens when sessions are not closed.

Our:

```python
finally:
    db.close()
```

prevents this.
