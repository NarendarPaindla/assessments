# 2. Theory

## Why Multiple Models?

A real E-Commerce application stores different types of data.

Example:

```text
Customer
   ↓
Adds Product
   ↓
Cart
   ↓
Order
   ↓
Payment
```

Storing everything in one table would be a disaster.

Instead:

```text
User
Category
Product
Cart
CartItem
Order
OrderItem
```

Each table has one responsibility.

# 9. Common Errors

---

## Error 1

```text
NoReferencedTableError
```

Reason:

Wrong ForeignKey.

Wrong:

```python
ForeignKey("category.id")
```

Correct:

```python
ForeignKey("categories.id")
```

---

## Error 2

```text
Table already exists
```

Delete old DB:

```bash
rm ecommerce.db
```

and recreate.

---

## Error 3

```text
ImportError
```

Forgot:

```python
import app.models
```

inside `main.py`.

---

## Error 4

```text
No such table
```

Make sure:

```python
Base.metadata.create_all(bind=engine)
```

exists.
