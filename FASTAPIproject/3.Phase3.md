# 2. Theory

## What is an API?

API = Application Programming Interface

Think of a restaurant.

```text
Customer
   ↓
Waiter
   ↓
Kitchen
```

The waiter is the API.

Example:

```text
Browser
   ↓
FastAPI
   ↓
Database
```

FastAPI receives requests and sends responses.

---

## What is a Route?

A Route is a URL endpoint.

Example:

```text
GET /
GET /products
GET /users
POST /orders
```

When a user visits:

```text
http://localhost:8000/
```

FastAPI executes the function attached to `/`.

---

## What is JSON?

Backend APIs usually return JSON.

Example:

```json
{
  "message": "Hello World"
}
```

JSON means:

JavaScript Object Notation

Used for communication between frontend and backend.

---

## Request Flow

```text
Client
   ↓
Route
   ↓
Function
   ↓
Response
```

Example:

```text
Browser
   ↓
GET /
   ↓
home()
   ↓
JSON Response
```

---

# 5. Explanation

Let's understand every line.

---

## Line 1

```python
from fastapi import FastAPI
```

Import FastAPI class.

Think:

```text
FastAPI Package
        ↓
FastAPI Class
```

Without importing it, we cannot create an application.

---

## Line 3

```python
app = FastAPI()
```

Creates FastAPI application object.

Equivalent:

```text
Start Backend Application
```

Everything will attach to `app`.

---

## Line 6

```python
@app.get("/")
```

This is called a decorator.

Meaning:

```text
When GET request comes to /
run the function below
```

Example:

```text
GET http://localhost:8000/
```

calls:

```python
home()
```

---

## Line 7

```python
def home():
```

Function executed when route is hit.

---

## Line 8–10

```python
return {
    "message": "Welcome to E-Commerce Backend API"
}
```

Returns JSON.

FastAPI automatically converts Python dictionary into JSON.

Python:

```python
{
    "message": "Welcome"
}
```

becomes:

```json
{
  "message": "Welcome"
}
```

---

# Internal Working

When request arrives:

```text
GET /
```

FastAPI:

```text
Find matching route
      ↓
Found "/"
      ↓
Execute home()
      ↓
Convert dictionary to JSON
      ↓
Send response
```

# 9. Common Errors

---

## Error 1

```text
ModuleNotFoundError: No module named fastapi
```

Reason:

FastAPI not installed.

Fix:

```bash
pip install fastapi
```

---

## Error 2

```text
IndentationError
```

Wrong:

```python
@app.get("/")
def home():
return {"message":"Hello"}
```

Correct:

```python
@app.get("/")
def home():
    return {"message":"Hello"}
```

Python requires indentation.

---

## Error 3

```text
SyntaxError
```

Wrong:

```python
return {
"message": "Hello"
```

Missing closing brace.

Correct:

```python
return {
    "message": "Hello"
}
```

---

## Error 4

```text
NameError: FastAPI is not defined
```

Reason:

Forgot import.

Add:

```python
from fastapi import FastAPI
```
